# FDE 客户需求问卷与跟进平台

状态：已获本地实施授权，待实际验收。目的：收集现状和设想，为深入访谈与方案准备材料，不将设想当最终需求。用户：非技术客户、代填者、已认证工作人员。仅本机；手机尺寸检查不等于手机可达。

## 必需要求与验收
- R1 简单问卷：11题，选择题为主，称呼、行业、当前问题为必填（星标），其他可跳过；草稿允许不完整。
- R2 详细模式：按客户类型、团队规模、20个行业、项目阶段与网站/流程/数据/AI需求方向组合通用及专项题，不确定时仅展示通用题。实际相关题每步最多5道，最后一步可少于5道；多方向共用的数据来源和权限只问一次。多数为带A/B/C标识的单选或多选，少量简答；分支及模式切换保留旧答案，旧自由文本在选择题中以原已填答案显示。未启用分支的旧答案在规则摘要中标明。题库与组合示例见QUESTION_BANK.md。
- R3 客户自行填或代填；自述代填不成为工作人员。工作人员必须登录走后台入口，actor由服务器确定。
- R4 草稿可保存、刷新、重启恢复；回访只凭随机能力凭证，编号不能读取。凭证丢失后联系工作人员人工核对，不能通过编号找回。
- R5 提交和补充生成追加原文快照；草稿、原文版本、后台备注、规则摘要分别保存；版本和备注带时间、身份。
- R6 后台登录退出、搜索、查看、阶段、备注、规则摘要与下次问题、Markdown/JSON和列表CSV导出。所有后台API强制鉴权，CSRF、输入校验、限流、无删除接口。
- R7 原文和备注作为文本呈现，脚本不执行；CSV公式防护、中文保留；提交请求去重，冲突拒绝覆盖；失败不报成功。
- R8 桌面/390px真实浏览器核心流程，API未授权/横向/身份伪造，服务重启持久性，独立虚构副本备份恢复，构建与依赖审查原始证据。

## 页面与流程
/ 为需求问卷：简单/详细选择→回答→保存草稿/提交；已有回访凭证可继续，已提交可提交新补充版本。
/guide 为使用与隐私说明；/admin/login；/admin 为搜索/阶段列表；/admin/intakes/:id 为详情、快照、备注、跟进、摘要、导出；未知路由404。
加载/无数据/失败/待保存/成功状态显式显示。回答更新不直接报已保存。并发版本冲突保留本页内容并提示刷新核对。

## 数据和权限
intakes保存当前工作草稿和revision、提交状态、阶段、创建来源；submissions保存不可变版本；notes追加备注；summaries保存规则整理结果（规则版本、来源revision）；audit保存动作/身份/时间；users与sessions负责认证。源码dist与data、backups隔离。
同源httpOnly、sameSite=strict Cookie；仅loopback HTTP，本轮secure=false；登录后服务端CSRF随机凭证，每个写接口校验请求头。客户能力凭证仅header传入，分享链接fragment不会发给服务器，浏览器本机保存凭证（仍有本机设备访问风险）。不存登录密码于浏览器。凭证/请求体不记日志。
收集目的在问卷说明；联系人可选，不收密码、Key、合同、单据、附件。真实客户数据本轮不使用；留存/删除请求由用户线下授权处理，无默认删除接口或定时任务。

## 边界
不公开、不LAN、不邮件、不上传、不外部AI、不多租户、不邀请账号、不自动报价、不客户联系、不个人网站集成、不迁移旧系统。不承诺维护期、费用或商业效果。
SQLite和同步写仅适合本机低并发；公开前需要TLS、数据库并发/备份/隐私留存、管理员账号生命周期、监控、安全和客户验收。无正式发布授权。
