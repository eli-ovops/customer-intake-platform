# 客户问卷题库

2026-10-06 用户授权的本机问卷调整。以下为当前实际题库；选项与规则由 src/questions.ts 和 src/question-options.ts 维护。题目不是最终项目范围或交付承诺。

必填：企业 / 团队称呼、所在行业、目前最想解决的问题。其他均可跳过，草稿允许不完整。每步最多5道实际相关题，最后一步可少于5道。

详细模式先选择客户类型、项目阶段和需求方向；客户类型与阶段各追加1题；个人、小团队、中型团队各追加1题，大团队追加2题；20个行业各有2题；不确定或旧行业采用通用题，不猜测行业。网站追加3题、流程追加3题、数据追加4题、AI追加5题，数据来源与权限在多选方向时只问一次。预算有范围时才显示可选简答。改变选择或模式保留旧答案，摘要将未启用分支的旧答案标明。
